# 기술 아키텍처

결정 D7(하이브리드 지도/검색), D8(Cloudflare + D1 + Drizzle) 기준.

## 1. 기술 스택

| 계층 | 선택 | 비고 |
|---|---|---|
| 프레임워크 | vinext + Vite (Next.js 16 호환 구조) | 프로토타입 그대로 |
| 언어 | TypeScript | |
| UI | React 19 | |
| 스타일 | Tailwind CSS 4 + `globals.css` | |
| 지도 렌더링 | MapLibre GL + OpenFreeMap (Positron/Bright) | **키 불필요·무료** |
| 장소 검색·지오코딩·외부 place id | **Kakao Local API** (D7′) | **무료·카드 불필요**, 서버 전용 REST 키 |
| 장소·경로 열기 | Google Maps URL | 키 불필요 |
| 런타임 | Cloudflare Workers | `worker/index.ts` |
| DB | Cloudflare D1 (SQLite) | |
| ORM | Drizzle | `db/schema.ts`(현재 비어 있음) 채울 예정 |
| 인증 | Google OAuth (Auth.js 호환) | |
| AI | **Groq**(무료, llama-3.3-70b) — 구조화 JSON 응답 | 승인 전 변경안 저장 (D8′) |

## 2. 하이브리드 지도/검색 데이터 흐름

```
[사용자 검색/AI 요청]
        │
        ▼
  Worker API Route ──► Kakao Local API (주소검색/키워드 장소검색)
        │                     │
        │              placeId, 좌표, 이름, 주소, 카테고리
        │                     ▼
        │              중복 판정(googlePlaceId / 좌표근접)
        │                     ▼
        │              ai_recommendation(proposedChanges) 저장
        ▼
  [클라이언트] MapLibre 렌더 ◄─ 좌표로 핀 표시 (렌더는 Google 불필요)
        │
        ▼
  사용자 승인 → bookmark/place/note 확정 → approval_history 기록
```

- **렌더링과 검색을 분리**: 지도 타일·핀은 MapLibre(무료), 장소 데이터만 Google.
- Google Maps URL로 "열기/경로"는 키 없이 링크 생성.

## 3. 서버 구조 (Cloudflare Worker)

- `worker/index.ts` — 진입점(이미지 최적화 + vinext app-router 핸들러). 유지.
- `db/index.ts` — `getDb()`가 D1 바인딩(`env.DB`)으로 Drizzle 인스턴스 생성.
- API Route(vinext app router `app/api/*`)에서 다음을 처리:
  - `/api/auth/*` — Google OAuth 콜백·세션
  - `/api/places/search` — Kakao Local 프록시(서버에 REST 키 보관)
  - `/api/boundaries`, `/api/bookmarks`, `/api/notes`, `/api/themes` — CRUD
  - `/api/ai/recommend` — 자연어 → 구조화 변경안(ai_recommendation)
  - `/api/ai/approve` — 승인 → 반영 + approval_history

## 4. 인증·데이터 소유권

- Google OAuth로 로그인, `user.googleAccountId`(sub)로 식별.
- 모든 데이터는 `userId` 스코프. 서버에서 세션 사용자와 대조해 접근 제어.
- 프로토타입의 `app/chatgpt-auth.ts`는 ChatGPT Sites 전용 → **Google OAuth로 교체 예정**
  (현재 메인 페이지에서는 미사용).

## 5. 시크릿·환경변수 (커밋 금지)

`.env`는 `.gitignore`에 포함됨. 다음은 배포 환경/시크릿 매니저로 주입:

- `GOOGLE_OAUTH_CLIENT_ID` / `GOOGLE_OAUTH_CLIENT_SECRET`
- `KAKAO_REST_API_KEY` (지오코딩·장소검색용, 서버 전용)
- `AUTH_SECRET` (세션 서명)
- `GROQ_API_KEY` (AI 추천, 서버 전용)

> D8 결정에 따라 AI 제공자는 별도 라운드에서 확정. 리포에는 키를 절대 커밋하지 않는다.

## 6. 성능 목표 (설계서 18장 계승)

- 지도 초기 표시 3초 이내
- 장소 검색 결과 3초 이내
- 일반 AI 요청 10초 이내
- 주변 활동 심층 검색: 비동기 작업 상태 표시
- 지도 이동·필터: 즉각 반응

## 7. 배포

- 프로토타입은 ChatGPT Sites용 `.openai/hosting.json`을 포함했으나 리포 이전 시 **제외**.
- 목표: Cloudflare Workers + D1 배포(`wrangler`). GitHub 연동 CI는 이후 구성.
