## 1. 서비스 개요

- **가칭**: 내 바운더리 (My Boundary Map)
- **한 줄 정의**: 집·직장 등 사용자가 설정한 생활 반경(바운더리) 안의 장소와 활동을
  테마별로 수집하고, 지도·목록·메모로 관리하며, AI가 새로운 장소 발견과 방문 계획을
  **제안(승인 후 반영)** 하는 개인 지도 서비스.
- **핵심 사용자**: 지역 내 교육·체험·원데이클래스·문화 활동 등 새로운 장소를 자주 찾는 개인.
- **서비스 형태**: 반응형 웹 · Google 로그인 · 개인 사용자 중심 MVP.

## 2. 서비스 설계 원칙 (변하지 않는 축)

1. **AI는 절대 자동 확정하지 않는다.** 모든 변경은 `제안 → 사용자 승인 → 반영 → 이력 기록`.
2. **원문 보존.** 사용자가 작성한 메모를 AI가 덮어쓰지 않는다. 정리 결과는 별도 제안으로 만든다.
3. **개인화는 동의한 데이터만.** 초기엔 오직 메모 + 평가만 사용. 위치·검색 기록은 동의 없이 안 씀.
4. **출처와 확인 시각을 남긴다.** 모든 장소는 좌표를 가지고, 정보의 출처·확인 시각을 기록한다.
5. **되돌릴 수 있다.** AI가 반영한 변경은 승인 이력과 연결되고 사용자가 되돌릴 수 있다.

## 3. 확정 결정 요약

질의응답으로 확정한 8가지 핵심 결정입니다. 자세한 근거는 [01-결정사항.md](./01-결정사항.md).

| # | 항목 | 결정 |
|---|---|---|
| 1 | 지도-바운더리 관계 | **단일 지도 + 다중 바운더리 오버레이** — 모든 장소가 하나의 지도에 모이고, 바운더리는 그 위에 켜고 끄는 반경 필터 레이어 |
| 2 | 장소 vs 활동 | **MVP는 Place 단일 엔터티** — 활동 정보(가격·일정·후기)는 주제별 구조화 메모로 관리. Program 분리는 3단계에서 검토 |
| 3 | 공유/협업 | **완전 개인용** — 공유·공동편집·공개지도 모두 MVP 제외 |
| 4 | 추천 실행 시점 | **온디맨드** — 사용자가 요청할 때만 AI 검색 실행. 정기 자동 탐색은 이후 확장 |
| 5 | 분류 용어 | **화면 용어는 "테마"** (내부적으로는 폴더 역할). 테마 1개 + 자유 태그 복수 |
| 6 | 메모 구조 | **UI는 단일 요약 메모로 시작, 데이터 모델은 다중 `Note[]`** — 주제별 다중 메모 UI는 2단계 AI 관리에서 확장 |
| 7 | 지도/검색 스택 | **하이브리드** — 렌더링은 MapLibre + OpenFreeMap(무료·키 불필요), 장소 검색·자동완성·Place ID·지오코딩은 Google Places API, 열기·경로는 키 없는 Google Maps URL |
| 8 | 백엔드/호스팅 | **Cloudflare Workers + D1(SQLite) + Drizzle ORM** + Google OAuth 인증 |

## 4. 해결하려는 문제

사용자는 관심 장소를 여러 지도·검색결과·메모앱·SNS에 흩어 저장한다. 그 결과:

- 저장한 장소를 다시 찾기 어렵다 / 저장한 이유가 기억나지 않는다.
- 집·직장 근처에 무엇이 있는지 한눈에 보기 어렵다.
- 서로 다른 주제의 장소가 뒤섞인다.
- 저장한 장소를 실제 방문 일정으로 연결하기 어렵다.
- 검색을 반복하며 이전 저장과 중복된다.
- 취향을 반영한 새 장소 발견이 어렵다.

→ 본 서비스는 **장소·활동·메모·평가·방문계획을 하나의 지도 중심 인터페이스로 통합**한다.

## 5. MVP 기능 범위

### 포함
- Google 로그인
- 바운더리 생성·수정·삭제 (주소 기반 중심 + 반경)
- 단일 지도에 다중 바운더리 오버레이 / 반경 필터
- 장소 검색(Google Places), 지도에서 직접 추가
- AI 자연어 장소 추천 → 미리보기 → **선택 승인 후 저장**
- 테마(단일) + 태그(복수) 분류, AI 자동 분류 제안
- 장소별 메모(모델은 다중, UI는 단일부터), 지도 노트
- 장소 평가(별점·방문상태), 메모·평가 기반 취향 요약
- 방문 순서 추천 + 예상 이동 시간 (4단계)
- Google Maps에서 장소·경로 열기
- Google 저장목록 파일 가져오기 / 데이터 내보내기 (5단계)
- 변경 이력과 승인 기록

### 제외 (MVP)
- 장소 자동 저장, 자동 예약·결제
- 실시간 위치 추적, 위치 기록 저장
- 사용자 간 공동 편집, 공개 지도 마켓, 지도 공유
- 네이티브 모바일 앱
- Google Maps 비공개 목록 무인 자동 쓰기
- 승인 없는 취향 학습
- 정기 자동 추천 (온디맨드만)

## 6. 미결 항목에 대한 MVP 기본값

1차 설계서 21장 미결 항목을, 확정된 핵심 결정에 맞춰 아래 기본값으로 정리합니다.
(이후 라운드에서 바뀔 수 있음)

| 미결 항목 | MVP 기본값 |
|---|---|
| 한 사용자가 여러 지도? | 지도는 1개(내 전체 지도). 여러 바운더리로 구분 |
| 지도-바운더리 관계 | 단일 지도 + 다중 바운더리 오버레이 (결정 #1) |
| 다른 사용자와 공유? | MVP 제외 (개인용) |
| 메모에 이미지·파일 첨부? | MVP 제외, 이후 검토 |
| 장소 정보 변경 시 자동 알림? | MVP 제외 (온디맨드 원칙) |
| 추천 검색 실행 시점 | 사용자가 실행할 때만 (결정 #4) |
| 정기 새 장소 탐색? | MVP 제외 |
| 공개 지도/템플릿? | MVP 제외 |
| 사용자 위치 기록 저장? | 저장 안 함 (개인정보 원칙) |
| 유료 확장 과금 기준 | MVP 범위 밖 |
| Google 가져오기 지원 형식 | CSV·JSON·KML (5단계) |
| 지도당 최대 장소 수 | 소프트 한도(예: 사용자당 500곳)로 시작, 하드 제한 없음 |
| 장소·활동 프로그램 별도 엔터티? | Place 단일, 활동은 메모로 (결정 #2) |
| 방문 완료 여부 수동 변경? | 예 — 사용자가 상태를 직접 변경 (저장/방문예정/다녀옴) |
| 취향 분석 삭제·초기화 정책 | 사용자가 개별 취향 항목을 수정·삭제 가능 |
