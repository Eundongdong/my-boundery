# 화면 구성

프로토타입 `app/BoundaryStudio.tsx`를 화면 구성의 기준(레퍼런스)으로 채택한다.
아래는 확정된 레이아웃과, 설계와 맞추기 위해 이후 확장할 지점이다.

## 1. 데스크톱 3분할 작업실 레이아웃

```
┌─────────────────────────────────────────────────────────┐
│ [상단바] 내 바운더리   · 모든 변경사항 저장됨 ·  샘플초기화 나 │
├──────────┬──────────────────────────────┬────────────────┤
│ 사이드바   │        지도 스테이지            │   인스펙터        │
│          │                              │                │
│ 내 바운더리 │   MapLibre 지도 캔버스          │ [장소] [지도노트]  │
│  ⌂ 집     │   · 바운더리 원(점선)           │                │
│  ▦ 직장    │   · 장소 핀(테마색)            │ 장소 목록(거리순)  │
│ [반경 슬라이더]│  · 스타일 전환(Positron/Bright)│  장소 카드…       │
│          │   · 범례(AI후보/저장)          │                │
│ 테마       │                              │ 장소 상세         │
│  ☕ 카페   │   ┌──────────────────────┐    │  · 방문상태       │
│  ♨ 점심   │   │ ✦ AI에게 장소 부탁하기  │    │  · 별점          │
│  ● 운동   │   └──────────────────────┘    │  · 메모(자동저장)  │
│          │                              │                │
│ 상태 필터   │                              │  ── 또는 ──       │
│  전체/가고픈 │                              │ AI 후보 미리보기   │
│  /다녀온   │                              │  후보카드+체크+추가 │
└──────────┴──────────────────────────────┴────────────────┘
```

## 2. 영역별 구성

### 상단바 (topbar)
- 브랜드 "내 바운더리"
- 중앙: 자동저장 인디케이터 "모든 변경사항 저장됨"
- 우측: 프로토타입 배지 / 샘플 초기화 / 프로필 아바타

### 좌측 사이드바 (sidebar)
- **내 바운더리**: 바운더리 카드(아이콘·이름·지역·반경·장소수), 반경 슬라이더(500m~2km)
  - MVP 확장: `+` 버튼으로 바운더리 생성(주소 검색 → 지오코딩 → 반경)
- **테마**: 토글 목록(점·아이콘·이름·개수), `+ 새 테마`
- **상태 필터**: 전체 / 가보고 싶은 곳 / 다녀온 곳 (세그먼트)
- 바운더리 팁

### 중앙 지도 스테이지 (map-stage)
- MapLibre 캔버스: 바운더리 원(점선 + 반투명 채움), 장소 핀(테마색), 선택 핀 강조, AI 후보 점선 핀
- 지도 스타일 전환(Positron / Bright, "NO KEY")
- 지도 헤딩(현재 바운더리·장소수), 범례(AI 후보 / 저장한 장소)
- **AI 컴포저**(하단): 자연어 입력 → 찾아보기
  - MVP 확장: 실제 Google Places 검색 자동완성 결합, AI 응답을 `ai_recommendation`으로 저장

### 우측 인스펙터 (inspector)
탭: **장소** / **지도 노트**

- **장소 패널**
  - 기본: 장소 목록(거리순) + 선택 시 장소 상세(방문상태 select, 별점, 메모 textarea)
  - AI 세션 중: 후보 미리보기(체크박스 선택·태그·조건일치 이유·AI 메모 초안·테마 select·모두/선택 추가)
  - **승인 흐름 = 설계서 철학과 일치**: 후보는 저장 전 미리보기, 선택한 것만 확정
- **지도 노트 패널**
  - 노트 제목/본문/콜아웃("이번 달 기준")/체크리스트/`@장소` 멘션
  - 서식 도구바(B/I/H₂/목록/체크/@장소) — 현재 시각적, 이후 실제 기능화

### 모바일
- 하단 탭: **지도 / 목록 / 노트**
- 지도 중심 화면, 장소 상세·메모는 전체 화면 패널, AI 입력은 하단 고정

## 3. 프로토타입 → MVP 확장 지점

| 화면 요소 | 프로토타입 | MVP에서 할 일 |
|---|---|---|
| 바운더리 | 집/직장 고정 | 사용자 생성·수정·삭제 (주소 지오코딩) |
| 장소 검색 | 없음(AI 데모만) | Google Places 검색·자동완성 결합 |
| AI 추천 | 정규식 샘플 | 실제 AI + Places, `ai_recommendation` 저장, 승인 이력 |
| 메모 | 장소당 1칸 | 모델은 다중 Note[], 2단계에서 주제별 메모 UI |
| 저장소 | localStorage | D1 + 사용자 계정 동기화 |
| 로그인 | 없음 | Google OAuth |
| 방문 계획 | 없음 | 4단계: 순서·이동시간·경로 링크 |
| 가져오기/내보내기 | 없음 | 5단계: Takeout 파싱, CSV/JSON/KML |

## 4. 유지할 UX 원칙 (프로토타입에서 계승)

1. **자동 저장** — 명시적 저장 버튼 없이 즉시 반영, 상단 인디케이터로 안내.
2. **AI는 미리보기 후 승인** — 점선 핀 = 미저장 후보, 선택한 것만 지도·목록에 확정.
3. **거리순 정렬 + 반경 필터** — 활성 바운더리 중심 haversine 거리로 정렬·필터.
4. **테마색 일관성** — 핀·목록 아이콘·후보 색이 테마색으로 통일.
5. **즉각적 UI 반응** — 지도 이동·필터는 지연 없이 반응(설계서 성능 목표).
